## How to play

Light beams travel in straight lines. Tap a mirror to turn it, tap a prism to flip it. Prisms split light into red, green and blue. Each target needs one exact color: beams reaching the same target add up, so yellow is red plus green, and white is all three. Filters only let their own colors through. Light up every target to win.

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Turn or flip an element | `Space` or `Enter` on the selected element | Tap the element |
| Select an element | Arrow keys: selects the nearest turnable element in that direction | Not applicable |
| Undo the last move | `Z` or `Backspace` | Undo button |
| Restart the level | `R` | Restart button |
| Pause | `Esc` or `P` | Pause button |
