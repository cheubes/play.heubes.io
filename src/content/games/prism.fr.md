## Comment jouer

Les faisceaux de lumière vont en ligne droite. Touche un miroir pour le faire pivoter, un prisme pour le retourner. Les prismes décomposent la lumière en rouge, vert et bleu. Chaque cible attend une couleur exacte : les faisceaux qui atteignent une même cible s'additionnent, le jaune est fait de rouge et de vert, le blanc des trois. Les filtres ne laissent passer que leurs couleurs. Allume toutes les cibles pour gagner.

## Contrôles

| Action | Clavier | Souris | Tactile |
|---|---|---|---|
| Faire basculer un élément | `Espace` ou `Entrée` sur l'élément sélectionné | Cliquer l'élément | Toucher l'élément |
| Sélectionner un élément | Flèches : sélection de l'élément orientable le plus proche dans cette direction | Sans objet | Sans objet |
| Annuler le dernier coup | `Z` ou `Retour arrière` | Bouton annuler | Bouton annuler |
| Recommencer le niveau | `R` | Bouton recommencer | Bouton recommencer |
| Pause | `Échap` ou `P` | Bouton pause | Bouton pause |
